> 目的：reading-the-wind の P式・E式に現れる全変数を、幾何代数 $\mathrm{Cl}(3)$ の
> 8個の基底と照合し、「基底なのか、そうでないのか」を一つずつ判定する。
>
> 証明強度：**[C] 作業仮説**。本ノートは主張ではなく、潰すべき候補の一覧である。

## 0. なぜこの照合が必要か

現行の拡張P式は、確定・要検討・候補を合わせて **21変数** を加算している。

$$P = xX + yY + zZ + Uu + vV + wW + hH + sS + eE + nN + cC + dD + aA + fF + kK + mM + gG + \rho R + \beta B + \sigma S + \tau T + \cdots$$

一方 $\mathrm{Cl}(3)$ の基底は **8個で閉じる**。

| 階数 | 個数 | 基底元 |
|---|---|---|
| スカラー | 1 | $1$ |
| ベクトル | 3 | $e_1, e_2, e_3$ |
| バイベクトル | 3 | $e_1e_2,\; e_2e_3,\; e_3e_1$ |
| 擬スカラー | 1 | $I = e_1e_2e_3$ |
| **計** | **8** | |

21 と 8 は両立しない。どちらかが間違っているか、**両者が違うものを数えている**かのいずれかである。

---

## 1. 診断：加算の型が混ざっている

全変数を定義文から読み直すと、少なくとも **5種類の異なる数学的対象**が一つの和に入っていることが分かる。

| 型 | 数学的正体 | 式の中での正しい位置 |
|---|---|---|
| **A. 基底** | 状態空間の独立な方向 | 加算項（これだけが正しい） |
| **B. 係数** | 無次元の倍率・減衰率 | 他項への**乗算** |
| **C. 演算子** | 状態から状態への写像 | 式に**作用**する |
| **D. 境界条件** | 領域の外側で与えられる値 | 式の**外**（境界で指定） |
| **E. 状態条件** | 閾値・場合分けの述語 | 式ではなく**条件分岐** |

型 B〜E を加算項として書くと、**次元の合わない量を足す**ことになる。
例：`sS`（規模＝無次元の倍率）と `xX`（力）は足せない。`sS × xX` なら意味を持つ。

これが 21 と 8 の食い違いの正体である可能性が高い。

## 2. 全変数の型判定（一次案）

### 2.1 型A：基底に入る候補 — **生成順**による8スロットの割り当て

軸は最初から3本あったのではなく、回転によって順に生まれた——という生成の筋書きに沿って並べ直す。
$\mathrm{Cl}(3)$ ではこれが幾何積の連鎖としてそのまま書ける。

#### 原初の3要素

| 段 | 原初要素 | $\mathrm{Cl}(3)$ | 対応する変数 | 役割 |
|---|---|---|---|---|
| 0-a | 双極の2点を結ぶ線 | ベクトル $e_1$ | $xX$ | 最初の向き |
| 0-b | それが回る面 | バイベクトル $B = e_1e_2$ | $\omega_z$ | 回転を生成する |
| 0-c | 面の外を作るもの | 擬スカラー $I = e_1e_2e_3$ | $iI$ | 3次元目を可能にする |

#### 生成の連鎖（すべて機械検証済み → §7）

| 段 | 生成 | 式 | 結果 | 対応変数 |
|---|---|---|---|---|
| 1 | $Y$ 軸 | $e_1 B$ | $e_2$ | $yY$ |
| 2 | $Z$ 軸 | $-(B I)$ | $e_3$ | $zZ$ |
| 3 | 第2の面 | $e_2 e_3$ | $e_{23}$ | $\omega_x$ |
| 4 | 第3の面 | $e_3 e_1$ | $e_{31}$ | $\omega_y$ |
| 5 | スカラー | $e_1 e_1$ | $1$ | $rR$ |

**原初 3 個 + 生成 5 個 = 8。** $\mathrm{Cl}(3)$ の席がちょうど埋まる。

#### この並べ替えが明らかにしたこと

**(1) 面内回転だけでは 3 次元目に届かない。**
$\{e_1,\; B\}$ から幾何積で到達できる線形空間は **4 次元**（$\mathrm{Cl}(2)$）で閉じる。
$\pi/2$ 回して $Y$、さらに $\pi$ 回しても $-X$ に戻るだけで、$Z$ は出ない。
**3 次元目には第 3 の原初要素が必要**であることが、閉包計算で確定した（§7）。

**(2) その第3要素をフレミングの法則に求めるのは循環論法。**
フレミングの法則は「3次元空間・電場・磁場・直交する3方向」がすでに存在することを前提とした
記憶術であり、3次元目を生成する場面では使えない。擬スカラー $I$ を原初要素として置く方が整合する。

**(3) $iI$ と擬スカラーの一致。**
擬スカラーは $I^2=-1$、全要素と可換、単独では観測にかからない。
`iI` を「観測できない潜在量」と定義した意図と独立に一致する。
生成順で見ると、**この見えない要素こそが $Z$ 軸を生んだ**という読み方になる。

**(4) 生成の履歴は線形独立性を壊さない。**
$e_2$ が $e_1$ から生まれても、$e_1 \perp e_2$ は保たれる。
「生まれた順序に依存している」ことと「線形従属である」ことは別問題である。

**(5) 交差は積に内在するので、加算項 $jJ$ は不要。**
$e_2$ を作るのに面 $B$（＝交差そのもの）が先に要る以上、交差は生成に内在する。
幾何積 $ab = a\cdot b + a\wedge b$ が交差項を自動生成するため、
$jJ$ を加算項として別立てすると**同じ交差を二度数える**。
$jJ$ の除去は交差の否定ではなく、交差を掛け算側に置く操作である。

#### 未解決：第3原初要素の一意性

閉包計算では $\{e_1, B, e_3\}$ からも 8 次元に到達する。
つまり第3の原初要素として $I$ を選ぶことは**代数からは強制されない**。
$I$ を選ぶ根拠は「見えない量が3次元目を作る」という理論側の動機であり、
現状は**選択であって導出ではない**。ここは [C] のまま残す。

### 2.2 型A外：基底ではないと判定される変数

| 変数 | 現行の扱い | 判定 | 理由 |
|---|---|---|---|
| $Uu$ | 基本変数（時間変化率） | **型C 演算子** | 変化率は $\partial/\partial t$。方向ではなく微分作用 |
| $vV$ | 基本変数（フラックス） | **型A だが従属** | ベクトル場は $e_1,e_2,e_3$ の線形結合。新しい席は不要 |
| $wW$ | 基本変数（エネルギー移流） | **型A だが従属** | 移流は $(\mathbf{v}\cdot\nabla)\phi$ 型。$vV$ と勾配から合成される |
| $jJ$ | 交差項 | **不要** | 幾何積 $ab = a\cdot b + a\wedge b$ が交差項を自動生成する |
| $hH$ | 確定変数（前歴） | **型C 演算子** | 過去の状態の畳み込み $\int K(t-s)P(s)\,ds$。記憶核 |
| $sS$ | 確定変数（規模） | **型B 係数** | スケール変換の倍率。無次元 |
| $eE$ | 確定変数（境界条件） | **型D 境界** | 定義そのものが「領域の外側」 |
| $nN$ | 要検討（非線形臨界） | **型E 条件** | 閾値の超過は述語であって項ではない |
| $cC$ | 要検討（連鎖） | **型C 演算子** | 多体結合。状態→状態の写像 |
| $dD$ | 要検討（散逸） | **型B 係数** | 減衰率。項の実部を負に引く倍率 |
| $aA$ | 候補（AI・技術基盤） | **型D 境界** | 応答関数そのものを外から書き換える |
| $fF$ | 候補（フィードバック） | **型C 演算子** | ループ利得。出力を入力に戻す写像 |
| $kK$ | 候補（鍵・転換条件） | **型E 条件** | $nN$ と同種。位置が違うだけの可能性 |
| $mM$ | 候補（信認） | **型B 係数** | $wW$ の利得を上下させる倍率 |
| $gG$ | 候補（世代間非対称） | **型D 境界** | 時間方向の境界条件（未来側が未定） |
| $\rho R$ | 候補（名実乖離） | **型B 係数** | 名目量と実質量の**比**。定義上、比は倍率 |
| $\beta B$ | 候補（移動性の非対称） | **型B 係数** | 境界の透過率。$eE$ に掛かる |
| $\sigma S$ | 候補（代替可能性） | **型B 係数** | 自由度の残存率 |
| $\tau T$ | 候補（適応時間差） | **型C 演算子** | 遅延作用素 $P(t-\tau)$ |

**集計：** 21変数のうち基底に残るのは 7（$rR$ を含めて 8）。
残り 13 は係数・演算子・境界・条件に再配置される。

## 3. この整理が解くもの

### 3.1 「第7項以降」問題の解消

現行 README は「第7項以降は無制限に発見されていく」とし、$\mathrm{Cl}(3)$ は「8で閉じる」と言う。
型の区別を入れると、**両方とも正しい**。

- **基底は 8 で閉じる**（状態空間の次元は有限）
- **演算子・係数・境界条件は無制限に増えてよい**（同じ空間への作用の仕方は無限にある）

「地図は永遠に完成しない」という主張は維持されるが、
未完成なのは**空間の次元ではなく作用の一覧**である、と言い換わる。

### 3.2 記号衝突の発見

現行の記号体系に、実務上まずい重複がある。

| 衝突 | 内容 |
|---|---|
| $sS$ と $\sigma S$ | 大文字 $S$ が重複 |
| $rR$ と $\rho R$ | 大文字 $R$ が重複 |
| $Uu$ と $\tau T$ | どちらも時間関連。$T$ は既に別用途 |

型の再配置と同時に改名するのが安全。

## 4. 反証テスト（これで潰す）

本ノートは仮説なので、以下が **一つでも失敗すれば $\mathrm{Cl}(3)$ 仮説は棄却**される。

### テスト1：$vV$ と $wW$ の従属性 → **結果: 気象領域では通過（データ不要）**

当初は観測データによる検証を想定したが、定義から決着した。

**$vV$（水蒸気フラックス）** は定義が $vV = q\,\mathbf{v}$（比湿 $\times$ 風速）。
スカラー倍されたベクトルなので、$e_1,e_2,e_3$ への分解は定義から従う。**従属で確定。**

**$wW$（熱移流）** は $wW = -(\mathbf{v}\cdot\nabla)T$、すなわち二つのベクトルの内積。
幾何積で書くと

$$\mathbf{v}\,\nabla T = \underbrace{\mathbf{v}\cdot\nabla T}_{\text{スカラー部} = wW} + \underbrace{\mathbf{v}\wedge\nabla T}_{\text{バイベクトル部} = \omega}$$

**$wW$ と $\omega$ が同一の幾何積の 2 成分として現れる。** 別変数を立てる必要がない。
当初の想定より強い結果。

**ただし社会領域では実行不能。** 気象の $xX,yY,zZ$ は実在の座標軸だが、
社会領域の $xX$（対立軸）・$yY$（権威構造）・$zZ$（チェック機能）は
互いの直交性が保証されず、線形結合が定義されていない。
「$0.3\times$対立軸 $+\ 0.7\times$権威構造」の意味を言えない以上、
分解可能性を問う手続き自体が存在しない。**現状は分類ラベルであって座標系ではない。**

| 領域 | 状態 |
|---|---|
| 気象・流体 | 検証可能・**通過** |
| 司法・組織・社会 | 検証手続きが未定義（現状はアナロジー） |

**分岐：** (A) 領域ごとに厳密／比喩の階層を明示する、
(B) 社会領域の3軸に数値指標を与えて内積を定義する。
(B) は「法令違憲判決13件で $zZ\approx 0$」という既存の数値化を3軸に拡張する路線。

---

### テスト2：$jJ$ の除去

**主張：** $jJ$ を式から落としても、幾何積が同じ情報を生成する。

**手順：** 砂川事件の分析（$eE$ が $zZ$ を上書きした構造）を、$jJ$ を使わず
$e_i e_j$ の幾何積だけで再記述する。

**判定：** 同じ結論が出れば $jJ$ は冗長。結論が変われば $jJ$ は独立情報を持っており、
代数が $\mathrm{Cl}(3)$ に収まらない証拠になる。

---

### テスト3：係数群の乗算移行

**主張：** $sS, dD, mM, \rho R, \beta B, \sigma S$ を加算から外して乗算に移しても、
既存の検証事例の結論は変わらない。

**手順：** 日独司法比較で、$hH$（前歴）を加算項ではなく
$zZ$ に掛かる係数 $g(hH)\cdot zZ$ として書き直す。

**判定：** 「ドイツは $hH$ を $zZ$ の設計原理に統合した」という既存の結論は、
むしろ**乗算のほうが自然に表現される**はず。加算でしか書けない事例が出れば型判定が誤り。

> 注：拡張E式には既に `f(eE)` `g(hH)` が「修正項」として書かれている。
> これは型の違いを部分的に察知していた形跡であり、テスト3はその一般化にあたる。

## 5. 未解決のまま残るもの

正直に列挙しておく。

1. **$7^2 + 24^2 = 625$ の意味づけ。**
   $7$（非スカラー基底数）と $24$（$|S_4|$、正四面体の対称群）に居場所があることと、
   それを**二乗して足す**理由があることは別。現時点で説明がない。

2. **$168 = |PSL(2,7)|$ の扱い。**
   数の一致はあるが、TTT内部で群が何かを置換している実例が示されていない。
   作用を書けるまでは採用しない。

3. **意味論的妥当性は別問題。**
   代数構造が閉じても、司法・気象の個別分析が正しくなるわけではない。
   それらは事実と論証で独立に立つ。$\mathrm{Cl}(3)$ 対応は**表記の整理**であって
   内容の保証ではない。

4. **TTT v2.0（[A]層）との接続は依然として未確立。**
   本ノートは reading-the-wind 側の記法整理であり、
   機械検証済みの TTT v2.0 と同一の理論であることを示すものではない。

## 7. 機械検証（付録）

同梱スクリプト `cl3.py` は $\mathrm{Cl}(3)$ を 8 次元の代数として実装し、
以下を実際に計算して確認する。ユークリッド計量 $e_ie_i=1$、blade は
$\{1, e_1, e_2, e_3, e_{12}, e_{23}, e_{31}, I\}$。

### 7.1 生成連鎖の確認

| 検算 | 結果 |
|---|---|
| $e_1 B = e_2$ | ✅ |
| $-(B I) = e_3$ | ✅ |
| $e_2 e_3 = e_{23}$ | ✅ |
| $e_3 e_1 = e_{31}$ | ✅ |
| $e_1 e_1 = 1$ | ✅ |
| $I^2 = -1$ | ✅ |
| $I$ が全 8 基底と可換 | ✅ |

### 7.2 閉包次元（原初集合ごとの到達範囲）

| 原初集合 | 幾何積で到達する線形空間の次元 |
|---|---|
| $\{e_1\}$ | 2 |
| $\{e_1,\; B\}$ | **4** ← 3次元目に届かない |
| $\{B,\; I\}$ | 4 |
| $\{e_1,\; B,\; I\}$ | **8** ✅ |
| $\{e_1,\; B,\; e_3\}$ | 8（$I$ の一意性は出ない） |
| $\{e_1,e_2,e_3\}$ | 8 |

**結論：** 原初要素は 3 個必要かつ十分。ただし第 3 要素の選び方は一意でない。
