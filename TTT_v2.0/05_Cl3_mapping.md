# Cl(3) 対応表 — 変数群を代数構造に照合する作業ノート

> 目的：reading-the-wind の P式・E式に現れる全変数を、幾何代数 $\\mathrm{Cl}(3)$ の 8個の基底と照合し、「基底なのか、そうでないのか」を一つずつ判定する。  
>   
> 証明強度：**\[C\] 作業仮説**。本ノートは主張ではなく、潰すべき候補の一覧である。

---

## 0\. なぜこの照合が必要か

現行の拡張P式は、確定・要検討・候補を合わせて **21変数** を加算している。

$$P \= xX \+ yY \+ zZ \+ Uu \+ vV \+ wW \+ hH \+ sS \+ eE \+ nN \+ cC \+ dD \+ aA \+ fF \+ kK \+ mM \+ gG \+ \\rho R \+ \\beta B \+ \\sigma S \+ \\tau T \+ \\cdots$$

一方 $\\mathrm{Cl}(3)$ の基底は **8個で閉じる**。

| 階数 | 個数 | 基底元 |
| :---- | :---- | :---- |
| スカラー | 1 | $1$ |
| ベクトル | 3 | $e\_1, e\_2, e\_3$ |
| バイベクトル | 3 | $e\_1e\_2,; e\_2e\_3,; e\_3e\_1$ |
| 擬スカラー | 1 | $I \= e\_1e\_2e\_3$ |
| **計** | **8** |  |

21 と 8 は両立しない。どちらかが間違っているか、**両者が違うものを数えている**かのいずれかである。

---

## 1\. 診断：加算の型が混ざっている

全変数を定義文から読み直すと、少なくとも **5種類の異なる数学的対象**が一つの和に入っていることが分かる。

| 型 | 数学的正体 | 式の中での正しい位置 |
| :---- | :---- | :---- |
| **A. 基底** | 状態空間の独立な方向 | 加算項（これだけが正しい） |
| **B. 係数** | 無次元の倍率・減衰率 | 他項への**乗算** |
| **C. 演算子** | 状態から状態への写像 | 式に**作用**する |
| **D. 境界条件** | 領域の外側で与えられる値 | 式の**外**（境界で指定） |
| **E. 状態条件** | 閾値・場合分けの述語 | 式ではなく**条件分岐** |

型 B〜E を加算項として書くと、**次元の合わない量を足す**ことになる。 例：`sS`（規模＝無次元の倍率）と `xX`（力）は足せない。`sS × xX` なら意味を持つ。

これが 21 と 8 の食い違いの正体である可能性が高い。

---

## 2\. 全変数の型判定（一次案）

### 2.1 型A：基底に入る候補 — 8スロットの割り当て

| 変数 | 現行の意味 | $\\mathrm{Cl}(3)$ の席 | 根拠 |
| :---- | :---- | :---- | :---- |
| $rR$ | 実部・顕在量 | **スカラー** $1$ | 階数0の量。向きを持たない総量 |
| $xX$ | 水平方向の力 | **ベクトル** $e\_1$ | 向きを持つ1階の量 |
| $yY$ | 縦方向の力 | **ベクトル** $e\_2$ | 同上 |
| $zZ$ | 鉛直方向の力 | **ベクトル** $e\_3$ | 同上 |
| $\\omega\_x$ | 角速度 x | **バイベクトル** $e\_2e\_3$ | GAでは回転は面の量（バイベクトル） |
| $\\omega\_y$ | 角速度 y | **バイベクトル** $e\_3e\_1$ | 同上 |
| $\\omega\_z$ | 角速度 z | **バイベクトル** $e\_1e\_2$ | 同上 |
| $iI$ | 虚部・潜在量 | **擬スカラー** $I$ | $I^2=-1$、全要素と可換、直接観測されない |

**8席がちょうど埋まる。** 特に $iI$ と擬スカラーの一致は注目に値する。 擬スカラーは「全体に浸透しているが単独では見えず、二乗すると負になる量」であり、 `iI` を「観測できない潜在量」と定義した意図と独立に一致している。

### 2.2 型A外：基底ではないと判定される変数

| 変数 | 現行の扱い | 判定 | 理由 |
| :---- | :---- | :---- | :---- |
| $Uu$ | 基本変数（時間変化率） | **型C 演算子** | 変化率は $\\partial/\\partial t$。方向ではなく微分作用 |
| $vV$ | 基本変数（フラックス） | **型A だが従属** | ベクトル場は $e\_1,e\_2,e\_3$ の線形結合。新しい席は不要 |
| $wW$ | 基本変数（エネルギー移流） | **型A だが従属** | 移流は $(\\mathbf{v}\\cdot\\nabla)\\phi$ 型。$vV$ と勾配から合成される |
| $jJ$ | 交差項 | **不要** | 幾何積 $ab \= a\\cdot b \+ a\\wedge b$ が交差項を自動生成する |
| $hH$ | 確定変数（前歴） | **型C 演算子** | 過去の状態の畳み込み $\\int K(t-s)P(s),ds$。記憶核 |
| $sS$ | 確定変数（規模） | **型B 係数** | スケール変換の倍率。無次元 |
| $eE$ | 確定変数（境界条件） | **型D 境界** | 定義そのものが「領域の外側」 |
| $nN$ | 要検討（非線形臨界） | **型E 条件** | 閾値の超過は述語であって項ではない |
| $cC$ | 要検討（連鎖） | **型C 演算子** | 多体結合。状態→状態の写像 |
| $dD$ | 要検討（散逸） | **型B 係数** | 減衰率。項の実部を負に引く倍率 |
| $aA$ | 候補（AI・技術基盤） | **型D 境界** | 応答関数そのものを外から書き換える |
| $fF$ | 候補（フィードバック） | **型C 演算子** | ループ利得。出力を入力に戻す写像 |
| $kK$ | 候補（鍵・転換条件） | **型E 条件** | $nN$ と同種。位置が違うだけの可能性 |
| $mM$ | 候補（信認） | **型B 係数** | $wW$ の利得を上下させる倍率 |
| $gG$ | 候補（世代間非対称） | **型D 境界** | 時間方向の境界条件（未来側が未定） |
| $\\rho R$ | 候補（名実乖離） | **型B 係数** | 名目量と実質量の**比**。定義上、比は倍率 |
| $\\beta B$ | 候補（移動性の非対称） | **型B 係数** | 境界の透過率。$eE$ に掛かる |
| $\\sigma S$ | 候補（代替可能性） | **型B 係数** | 自由度の残存率 |
| $\\tau T$ | 候補（適応時間差） | **型C 演算子** | 遅延作用素 $P(t-\\tau)$ |

**集計：** 21変数のうち基底に残るのは 7（$rR$ を含めて 8）。 残り 13 は係数・演算子・境界・条件に再配置される。

## 3\. この整理が解くもの

### 3.1 「第7項以降」問題の解消

現行 README は「第7項以降は無制限に発見されていく」とし、$\\mathrm{Cl}(3)$ は「8で閉じる」と言う。 型の区別を入れると、**両方とも正しい**。

- **基底は 8 で閉じる**（状態空間の次元は有限）  
- **演算子・係数・境界条件は無制限に増えてよい**（同じ空間への作用の仕方は無限にある）

「地図は永遠に完成しない」という主張は維持されるが、 未完成なのは**空間の次元ではなく作用の一覧**である、と言い換わる。

### 3.2 記号衝突の発見

現行の記号体系に、実務上まずい重複がある。

| 衝突 | 内容 |
| :---- | :---- |
| $sS$ と $\\sigma S$ | 大文字 $S$ が重複 |
| $rR$ と $\\rho R$ | 大文字 $R$ が重複 |
| $Uu$ と $\\tau T$ | どちらも時間関連。$T$ は既に別用途 |

型の再配置と同時に改名するのが安全。

## 4\. 反証テスト（これで潰す）

本ノートは仮説なので、以下が **一つでも失敗すれば $\\mathrm{Cl}(3)$ 仮説は棄却**される。

### テスト1：$vV$ と $wW$ の従属性 ★最優先

**主張：** $vV$ と $wW$ は $xX, yY, zZ$ の線形結合として書ける。

**手順：** 山形・能登の気象事例で、水蒸気フラックス $vV$ を東西・南北・鉛直の3成分に分解する。 分解できれば従属、できなければ $\\mathrm{Cl}(3)$ の3次元ベクトル空間では足りない。

**判定：** 分解不能なら**棄却**。基本6変数が本当に独立なら代数は $\\mathrm{Cl}(3)$ ではない。

---

### テスト2：$jJ$ の除去

**主張：** $jJ$ を式から落としても、幾何積が同じ情報を生成する。

**手順：** 砂川事件の分析（$eE$ が $zZ$ を上書きした構造）を、$jJ$ を使わず $e\_i e\_j$ の幾何積だけで再記述する。

**判定：** 同じ結論が出れば $jJ$ は冗長。結論が変われば $jJ$ は独立情報を持っており、 代数が $\\mathrm{Cl}(3)$ に収まらない証拠になる。

---

### テスト3：係数群の乗算移行

**主張：** $sS, dD, mM, \\rho R, \\beta B, \\sigma S$ を加算から外して乗算に移しても、 既存の検証事例の結論は変わらない。

**手順：** 日独司法比較で、$hH$（前歴）を加算項ではなく $zZ$ に掛かる係数 $g(hH)\\cdot zZ$ として書き直す。

**判定：** 「ドイツは $hH$ を $zZ$ の設計原理に統合した」という既存の結論は、 むしろ**乗算のほうが自然に表現される**はず。加算でしか書けない事例が出れば型判定が誤り。

> 注：拡張E式には既に `f(eE)` `g(hH)` が「修正項」として書かれている。 これは型の違いを部分的に察知していた形跡であり、テスト3はその一般化にあたる。

## 5\. 未解決のまま残るもの

正直に列挙しておく。

1. **$7^2 \+ 24^2 \= 625$ の意味づけ。** $7$（非スカラー基底数）と $24$（$|S\_4|$、正四面体の対称群）に居場所があることと、 それを**二乗して足す**理由があることは別。現時点で説明がない。  
     
2. **$168 \= |PSL(2,7)|$ の扱い。** 数の一致はあるが、TTT内部で群が何かを置換している実例が示されていない。 作用を書けるまでは採用しない。  
     
3. **意味論的妥当性は別問題。** 代数構造が閉じても、司法・気象の個別分析が正しくなるわけではない。 それらは事実と論証で独立に立つ。$\\mathrm{Cl}(3)$ 対応は**表記の整理**であって 内容の保証ではない。  
     
4. **TTT v2.0（\[A\]層）との接続は依然として未確立。** 本ノートは reading-the-wind 側の記法整理であり、 機械検証済みの TTT v2.0 と同一の理論であることを示すものではない。
