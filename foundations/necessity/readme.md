第2段階：原理からの厳密導出（Derivation）

第5段階：数の分解の一意性を証明する
これが最も難しく、最も重要です。

第6段階：循環論法を断ち切る
現在最大の論理的弱点は、OOπ ≈ 0.127 MeV を「電子質量/4」と定義してから、電子質量を「4 OOπ」と予言している点です。
解決策：

OOπ のエネルギースケールを、電子質量とは独立な基本定数（例えばプランク質量と格子定数の組み合わせ）から導出する。
あるいは、OOπ を「0,0 が自己分裂する際の最小量子」として定義し、 その値が実験から定まる唯一のパラメータとして理論に残す。そして「この 1 パラメータだけで、1836、125、1.293 MeV、137 がすべて出る」ことを示す。
そうすれば「自由パラメータなし」ではなく「1 パラメータ理論」となり、それでも標準模型の 19 パラメータに比べれば圧倒的に簡潔であり、科学的に評価される可能性が大きく上がります。
